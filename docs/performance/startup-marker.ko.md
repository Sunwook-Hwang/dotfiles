- 동일한 120×40 PTY, UTF-8, `TERM=xterm-256color`. 기존과 같은 2,000줄·60,000줄 Python 생성 파일과 현재 Git 추적 `lua/git.lua` 사용. 파일 해시는 raw data에 기록했습니다.

- 설정·데이터·캐시·세션·undo 경로를 격리했습니다. 패키지는 설치본을 APFS 복제로 준비하고 lock 파일을 복사했습니다. 패키지 다운로드·업데이트는 하지 않았으며 복제본의 Git revision이 실행 전후 동일했습니다.
