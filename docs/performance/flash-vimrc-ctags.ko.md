두 설정의 실제 gd 매핑을 사용하고 FLASH의 LSP만 끕니다. 새 Git 프로젝트에
Python 모듈 100개와 서로 다른 함수 1,000개, 2천 줄 main.py를 만듭니다.
첫 gd는 인덱스 생성부터 콜백·파일 열기·redraw까지 포함합니다. 이후 20회 탐색은
인덱스를 재사용하고 원본 파일로 돌아오는 비용을 제외합니다. 각 프로세스의
20회 중앙값을 다시 7회 프로세스에 걸쳐 요약합니다. 순서를 교대해 총 14회 측정합니다.

프로세스마다 21번 모두 기대한 함수 정의에 도달해야 통과합니다. PTY·격리 조건은
3개 편집기 비교와 같고, 최대 RSS에는 이후 공통 편집 작업까지 포함됩니다.
자식 ctags 프로세스 메모리는 제외합니다. LSP, 미저장 내용의 정확성, 중복 정의,
NFS·서버 환경 비교가 아닙니다. pvi의 LSP 없는 gd를 억지로 동일하게 바꾸지
않았으므로 이 ctags 실험에는 pvi를 넣지 않았습니다.
